CASIO fx-991ES PLUS Scientific Calculator

Files
- index.html: calculator markup and accessible key labels
- styles.css: responsive calculator styling
- script.js: calculator interactions and expression parser
- codes.txt: combined source, separated by file

Run locally
1. Keep index.html, styles.css, and script.js in the same folder.
2. Open index.html in a modern browser. No build tools or external libraries are required.

Input shortcuts
- Enter or =: calculate
- Backspace: delete the previous character
- Escape or Delete: clear
- Left / Right: move the expression cursor
- Up / Down: recall expression history
- You can type expressions and function names such as sin(30), log(100), sqrt(81), and pi.
